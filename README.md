# UCS761_Deep_Learning

This repository contains the lab assignments completed as part of the UCS761 Deep Learning course. The assignments demonstrate the implementation of key machine learning and neural network concepts including perceptron-based logic gates, logistic regression, multiple linear regression, and multilayer perceptron with backpropagation using real-world datasets.

---

## Assignment 1 – Perceptron for Logic Gates
A single layer perceptron is implemented to simulate basic logic gates including **AND, OR, NAND, and NOR** using their truth tables as training data.

**Reference:**  
https://www.enjoyalgorithms.com/blog/design-perceptron-to-learn-and-or-xor-gates 

---

## Assignment 2 – Logistic Regression using Perceptron
A **single layer perceptron with sigmoid activation** is implemented to perform logistic regression for **glass classification**.

**Dataset:**  
https://www.kaggle.com/datasets/uciml/glass

**Reference:**  
https://medium.com/analytics-vidhya/logistic-regression-using-single-layer-perceptron-neural-network-slpnn-31757c792d5d

---

## Assignment 3 – Multiple Linear Regression using Perceptron
A perceptron model is used to implement **multiple linear regression** to predict a continuous output variable using multiple input features.

**Dataset:**  
https://www.kaggle.com/datasets/hussainnasirkhan/multiple-linear-regression-dataset

---

## Assignment 4 – Multilayer Perceptron using Backpropagation
A **multilayer perceptron (MLP)** is implemented using the **backpropagation algorithm** to predict the **age of abalone** from physical measurements.

**Dataset:**  
https://archive.ics.uci.edu/dataset/1/abalone

---

## Assignment 5 – Steel Surface Defect Classification  
A deep learning model is implemented to classify **surface defects in hot-rolled steel strips** using grayscale images.

**Dataset:**  
https://www.kaggle.com/datasets/sukubhardwikh/neu-surface-defect-database  

**Models Used:**  
**ResNet50, InceptionV3 (Google Inception), EfficientNet**

---

## Assignment 6 – Electrical Consumption Forecasting  
Deep learning models are implemented to forecast **electrical consumption for the next 10 years** using time series data.

**Dataset:**  
https://www.kaggle.com/code/nageshsingh/predict-electricity-consumption  

**Models Used:**  
**RNN, LSTM, GRU, Vision Transformer**

---

## Assignment 7 – Image Super Resolution  
A GAN-based approach is implemented to enhance **low-resolution images into high-resolution images**.

**Dataset:**  
https://www.kaggle.com/datasets/adityachandrasekhar/image-super-resolution  

**Models Used:**  
**GAN, SRGAN, ESRGAN**
